# How To Use This Guide

Follow the levels in order.

Do not jump to microservices before learning API, database, and transactions.

## Daily Study Plan

```text
Day plan:
1 hour reading
1 hour coding
30 minutes notes
30 minutes revision
```

## Best Method

Read one topic. Build one small example. Then explain it in your own words.

If you cannot explain it simply, learn it again.

## What To Build

After every core section, build a hands-on backend project to prove your skill:

- After [REST APIs](/spring-boot/rest-api): Build the [Todo API](/projects/todo-api-full-build)
- After [Database & Security](/spring-boot/spring-security-production): Build the [Notes API with JWT](/projects/notes-api-full-build)
- After [JPA & Roles](/spring-boot/jpa-hibernate): Build the [Blog API with Roles & Comments](/projects/blog-api-full-build)
- After [Transactions & Concurrency](/database/locking-isolation): Build the [Ecommerce Backend](/projects/ecommerce-full-build)
- After [Message Queues](/advanced/message-queues): Build the [Notification Worker](/projects/notification-worker-full-build)
- After [Docker](/advanced/docker-kubernetes): Complete the [Deployment Lab](/projects/deployment-lab) and [Incident Debugging Lab](/projects/incident-debugging-lab)
