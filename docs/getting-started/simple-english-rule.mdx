# Simple English Rule

This website uses simple English.

## Bad Style

```text
JWT facilitates stateless authentication.
```

## Good Style

```text
JWT helps backend know who is sending request, without saving login data in server.
```

## Rule

- Use short sentences
- Explain hard words
- Use real examples
- Show code after simple meaning
- Add common mistakes

## Example

```text
API means a way for two apps to talk.

Frontend sends request.
Backend checks request.
Backend sends response.
```
