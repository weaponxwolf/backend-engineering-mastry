# Backend Engineering Roadmap: Junior to Senior & Staff Architect

Becoming a top-tier backend engineer is not about memorizing framework syntax or chasing fashionable tech stacks.
It is about mastering the **fundamental physical layers of computing**—from operating system threads and TCP sockets to PostgreSQL 8 KB page storage, ACID concurrency, distributed consensus, and multi-region high availability.

This roadmap outlines the definitive engineering progression from novice to Staff Architect. Each level defines:
1. **Core Conceptual Masterclasses** (exhaustive textbook-grade chapters).
2. **Knowledge Gate Checklist** (concrete technical skills you must demonstrate before advancing).
3. **Required Portfolio Capstone** (real, runnable projects with full test suites).
4. **Common Traps & Red Flags** (mistakes that fail technical interviews).
5. **Senior Diagnostic Questions** (self-assessment test).

---

## Milestone 0: Web & Networking Foundations (Level 0)

Before touching Spring Boot, you must understand how bytes move across the public internet, how operating systems manage sockets, and why servers exist.

### Core Masterclasses
- [What is Backend? Systems, Lifecycles & Invariant Protection](/backend-basics/what-is-backend)
- [Client-Server Architecture, TCP/IP Stack & Edge Gateways](/backend-basics/client-server)
- [HTTP Internals, REST Architecture & JSON API Standards](/backend-basics/http-json-api)

### Knowledge Gate Checklist
<Check>
- Explain the difference between TCP and UDP, and walk through the TCP 3-way handshake and 4-way termination.
- Deconstruct an annotated `curl -v` terminal trace (DNS lookup, TCP SYN/ACK, TLS 1.3 handshake, HTTP headers, Keep-Alive).
- Explain what the `TIME_WAIT` socket state is, why it lasts for $2 \times \text{MSL}$ ($60\text{s}$), and how it exhausts ephemeral ports in microservices.
- Understand the 3 network socket timeout boundaries: Connection Timeout, Read/Socket Timeout, and Execution Timeout.
- Differentiate between a Forward Proxy (protects clients) and a Reverse Proxy (protects servers).
- Explain the difference between CPU-bound, I/O-bound, and Memory-bound workloads and their hardware bottlenecks.
</Check>

### Common Traps & Red Flags
- **Trusting Client Data**: Accepting prices, discounts, or user privileges directly from HTTP request JSON payloads.
- **Conflating Status Codes**: Returning `200 OK` with `{"error": "User not found"}` instead of standardized RFC 9457 Problem Details with HTTP 404.
- **Ignoring Socket Timeouts**: Making outbound HTTP requests without explicit connection and read timeouts, allowing hanging sockets to exhaust thread pools.

### Knowledge Gate Checklist
<Check>
- Understand the physical structure of an $8\text{ KB}$ PostgreSQL database page (PageHeader, ItemId line pointers, tuple headers with `xmin`/`xmax`, and TOAST tables).
- Explain the Leftmost Prefix Rule for composite indexes and calculate Index Selectivity ($S = \text{Cardinality} / N$).
- Design Covering Indexes with `INCLUDE` to achieve zero-heap Index-Only Scans.
- Deconstruct `EXPLAIN (ANALYZE, BUFFERS)` output: startup vs total cost math, buffer hit ratios, and physical join algorithms (Nested Loop, Hash Join, Merge Join).
- Size HikariCP connection pools using Brett Wooldridge's formula: $\text{Pool Size} = (\text{Cores} \times 2) + \text{Effective Spindles}$.
- Prevent the Lock Queue Trap during migrations using `SET lock_timeout = '2s'` and `CREATE INDEX CONCURRENTLY`.
- Understand PostgreSQL MVCC heap tuple headers (`xmin`, `xmax`, `t_ctid`) and the Write Skew anomaly under Repeatable Read.
</Check>

### Common Traps & Red Flags
- **Using Hibernate `ddl-auto: update` in Production**: Silent schema corruption and table locks.
- **Unindexed Foreign Keys**: Deleting or updating a parent table acquires a table-level lock on the unindexed child table, paralyzing web traffic.
- **Offset Pagination on Large Tables**: `OFFSET 1000000` scans and discards 1,000,000 rows; always use $O(1)$ Keyset Pagination.
