# Spring Backend Mastery

A beginner-to-advanced backend engineering documentation website inspired by `33-js-concepts`, built with Mintlify and MDX.

## Run Locally

Install dependencies:

```bash
npm install
```

Start the docs server:

```bash
npm run dev
```

This starts the Mintlify docs server from the `docs` folder.

## Validate Docs

```bash
npm run validate
```

Check build validation and broken links:

```bash
npm run check
```

## Goal

Teach backend engineering in simple English:

- Java and JVM basics
- Spring Boot REST APIs
- SQL, JPA, Hibernate, and transactions
- Security, testing, logging, and production practices
- Caching, queues, microservices, and distributed systems
- System design and interview preparation

## Writing Rule

Use short sentences. Explain every hard word. Add examples before heavy theory.
